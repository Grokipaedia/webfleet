Check a real URL (V2 — DNS check is real, everything else is honestly limited)

What this can actually tell you, honestly: the DNS check is real — it queries a public DNS-over-HTTPS resolver and reports whether the domain actually resolves. The reachability check can only detect a hard network failure (DNS totally failing, or the connection being refused outright) — browsers do not allow a page to read the real HTTP status code, headers, or body of a request to a different domain unless that domain explicitly permits it (a security restriction called CORS, not a shortcut taken here). That means this page cannot honestly tell you whether a site returns a 200, a 404, or a 500 — only whether a connection attempt didn't immediately fail. SSL certificate details and broken-link scanning aren't shown at all in this version, because neither is possible from a page like this running entirely in your browser — both genuinely require a small backend or a GitHub Action making the request server-side, which is the planned next step (V3), not something skipped here.
